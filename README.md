# WanderIndia 🇮🇳

> A modern, responsive travel website that helps people discover India's destinations, heritage, spirituality, nature and travel experiences through an immersive visual interface.

## ✨ Project Overview

**WanderIndia** is a front-end travel discovery project built to showcase India through curated destination pages and a premium editorial-style interface.

The project focuses on destination discovery, Indian heritage and culture, spiritual and pilgrimage destinations, mountain and nature escapes, responsive presentation, interactive filtering, reusable destination-page patterns, and accessible navigation.

## 🧭 Destination Information

Destination content is organised around useful traveller context such as location, what the destination is known for, main attractions, cultural or spiritual significance, suggested travel season, how to reach, local/practical tips and nearby places.

For pilgrimage destinations, the site also highlights respectful visitor behaviour and cultural context.

## ⚡ Performance Considerations

The project uses native lazy loading for below-the-fold images, reusable CSS patterns and minimal JavaScript dependencies.

Some original image assets are still relatively large. A production deployment can improve performance further by converting large JPG/PNG files to WebP/AVIF, resizing oversized source images and serving responsive image sizes.

## ♿ Accessibility

The project includes semantic HTML, descriptive image alt attributes, accessible navigation labels, keyboard-friendly native links/buttons and responsive text sizing.
